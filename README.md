# MEDORA · instaladores

Este repositorio solo publica los **instaladores** de MEDORA (Sistema de gestión hospitalaria). El código fuente es privado.

- **Windows:** descarga `MEDORA-X.Y.Z-Setup-x64.exe` de la [última versión](../../releases/latest). Cada instalador va con su `.exe.sha256`; el launcher verifica ese hash antes de instalar una actualización.
- **Linux / macOS:** `.AppImage`, `.deb` y `.dmg` en la misma versión.

Las PCs con MEDORA instalado se actualizan solas desde aquí.
